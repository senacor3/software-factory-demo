- (decision) Visual inspiration: ford.de (fetched live) -- Ford Blue (#003478) + black/white palette, bold sans headings, card-grid layout rhythm, high-contrast CTAs, generous whitespace. Not Ford Performance red.
- (decision) Scope: all existing freight-tenders Angular pages -- tender overview (list), create-tender form, tender-detail page (remarks/offers + add-forms). Backend/API untouched.
- (decision) Sortable tables replace the current plain <ul> lists where reasonable: tender overview (open/closed lists) and the detail page's remarks/offers lists. Single-column click-to-sort, ascending/descending toggle, no pagination (small datasets, internal demo).
- (decision) German UI copy throughout is inherited from epic-demo-app's existing Boundaries (backend/API stays English) -- not a new UX decision, carried forward.
- (assumption) Form factor: responsive web, desktop-primary -- freight-tender management is a B2B back-office task, used mainly on laptop/desktop; mobile gets basic readability, not a dedicated mobile-first layout.
- (assumption) Stakes: internal demo app, not consumer-facing or regulated -- WCAG AA as a floor, not an extensive accessibility audit.
- (assumption) Exact Ford Blue hex (#003478) approximated from public brand knowledge, not pixel-sampled from the live site (ford.de's rendered colors weren't inspectable via text fetch) -- close enough for an internal demo; adjust by eye if it reads off.
- (decision) Mock coverage: key-screen mocks rendered for overview and detail (the two load-bearing/complex surfaces); create-tender form stays spine-only (simple two-field form, no mock needed).
- (decision) Reviewer Gate declined -- finalizing without a separate review-lens pass; the two consequential decisions (palette, sort behavior) were already confirmed directly with the user.
- (event) spines finalized
- (change) Applied doc_standards (structure+prose lens) edits: fixed the three-way inconsistent error-placement rule (canonical: below the form, above its submit button, in both spines); trimmed DESIGN.md's Status pill/Buttons entries to visual-only, deferring copy/placement to EXPERIENCE.md; replaced 'click' with 'select' throughout EXPERIENCE.md per the Microsoft Writing Style Guide; fixed 'e.g.' and minor slash/grammar/parallelism issues.
- (decision) Declined two prose-lens findings: renaming ampersand headings ('Brand & Style' etc., 'Do's and Don'ts', 'Inspiration & Anti-patterns') -- these are canonical section names mandated by the DESIGN.md/EXPERIENCE.md spine specs themselves, not this document's own prose choice to revise.
- (decision) Declined structure finding #5 (merge Elevation & Depth with Shapes) -- both are separately named, order-locked sections per the external google-labs-code/design.md spec; merging would deviate from the spec DESIGN.md is meant to conform to.
